Vyriesene chyby
===============

1. Produktova stranka sa nezobrazovala
---------------------------------------
Chyba:
Route /products/[slug] nebola spravna Next.js App Router route.

Dovod:
Produktova stranka bola ulozena v module, ale v priecinku src/app/products/[slug] nebol
spravny page.tsx subor. Next.js preto route nevedel korektne nacitat.

Riesenie:
Bol vytvoreny src/app/products/[slug]/page.tsx, ktory importuje produktovu prezentaciu
z src/presentation/products/page.tsx. Route teraz nacitava produkt podla slug-u z databazy.


2. CSS sa na produktovej stranke nepouzivalo spravne
----------------------------------------------------
Chyba:
CSS Module triedy mali hodnotu undefined, napr.:
class="site-shell undefined"

Dovod:
V next.config.ts bolo vlastne Turbopack pravidlo pre vsetky CSS subory. To sposobilo,
ze subory *.module.css boli spracovane ako obycajny globalny CSS a nevytvorili
spravne CSS Module mapovanie.

Riesenie:
Vlastne Turbopack CSS pravidlo bolo odstranene z next.config.ts. Next.js teraz pouziva
standardne spracovanie CSS Modules a triedy sa generuju s lokalnym hashom.


3. Nespravne CSS Module nazvy v komponente
------------------------------------------
Chyba:
Komponent pouzival styles.productPage a styles.eyebrow, hoci tieto exporty
neexistovali v CSS Module alebo boli globalne triedy.

Dovod:
CSS trieda product-page obsahuje pomlcku a globalna trieda eyebrow nemala byt citana
z CSS Module objektu.

Riesenie:
Pomlckove triedy sa pouzivaju cez styles["nazov-triedy"] a globalna trieda eyebrow
sa pouziva priamo ako className="eyebrow".


4. Chybajuci obrazok produktu vracal 404
----------------------------------------
Chyba:
Obrazok /img/products/test_jacket_green_maneq.png vracal HTTP 404.

Dovod:
Obrazok bol uvedeny v seed datách, ale subor sa nenachadzal v public/img/products.

Riesenie:
Referencia na neexistujuci obrazok bola odstranena zo scripts/seed.ts a stara referencia
bola odstranena aj z databazy opakovaným spustenim seed skriptu.


5. Next Image fill hlasil neplatnu poziciu rodica
------------------------------------------------
Chyba:
Next Image hlasil:
Image with src ... has fill and parent element with invalid position.

Dovod:
Komponent Image s vlastnostou fill potrebuje rodicovsky element s position relative,
absolute alebo fixed.

Riesenie:
Na hlavny obrazok a tlacidla miniatur bola pridana position: relative.


6. CSS parser odmietal :global zapis
------------------------------------
Chyba:
Turbopack hlasil, ze :global nie je platny pseudo-selector.

Dovod:
CSS Module obsahoval zapis :global(...) v konfiguracii, ktora ho spracovavala
ako bezny CSS selector.

Riesenie:
Globalne selektory boli odstranene alebo nahradene lokalnymi CSS Module triedami.
Komponent bol upraveny tak, aby pouzival lokalne mapovanie styles.


Overenie
--------
- npx tsc --noEmit
- npm run build
- GET /products/krivan-pro-3l -> HTTP 200


7. Produktovy panel na homepage bol necitatelny
------------------------------------------------
Chyba:
Produktovy nahľad bol velmi uzky a bez obsahu. Popis bol vedla neviditelneho
produktoveho pola, preto produkt nebol dobre viditelny.

Dovod:
Element product-preview bol prazdny a layout pouzival prvy stlpec so sir kou
iba 128 px. Zaroven JSX obsahoval vela one-line blokov, ktore sa tazko udrziavali.

Riesenie:
Homepage bola prepisana do citatelnych viacriadkovych React komponentov.
Produktovy panel teraz obsahuje lokalne produktove obrazky, velky produktovy
nahľad, popis v samostatnom pravom stlpci a vyber obrazkov pod nimi.
Na mobiloch sa panel skladá do jedneho stlpca.


8. V databaze boli iba data jedneho produktu
--------------------------------------------
Chyba:
Produktovy katalog obsahoval iba Kriváň Pro 3L, hoci v public/img/products boli
dostupne obrazky aj pre batoh a technicke nohavice.

Dovod:
Seed skript vytvaral iba jeden produkt a ostatne obrazky neboli prepojene
s produktami, variantmi ani kategoriami v databaze.

Riesenie:
Seed skript teraz vytvara aj:
- Vertex Alpine 40L s obrazkami batoha,
- Tatran Ripstop Pants s obrazkami nohavic.

Pre oba produkty sa vytvori kategoria, farba, velkostne varianty, ceny, sklad,
galeria obrazkov a technicke atributy. Seed je idempotentny a API teraz vracia
tri aktivne produkty.


9. Produktovy modul porusoval Clean Architecture
-------------------------------------------------
Chyba:
Produktova page a API route obsahovali priame Drizzle dotazy, databazove tabulky
a mapovanie databazovych riadkov do UI modelov.

Dovod:
Domain, application, infrastructure a presentation vrstvy neboli oddelene.
Presentation vrstva preto priamo zavisela od PostgreSQL implementacie.

Riesenie:
Produktovy modul bol rozdeleny na:
- domain: produktove typy a ProductRepository kontrakt,
- application: use-cases GetProductDetail a SearchProducts,
- infrastructure: DrizzleProductRepository,
- presentation: Next.js page, API routes a klientsky komponent.

Vytvorenie konkretnej infrastruktury je v composition.ts, takze application
vrstva zostava nezavisla od Drizzle a databazy.


10. Stav košíka sa strácal medzi stránkami
-------------------------------------------
Chyba:
Košík používal localStorage ako zdroj cien a položiek, takže server nevedel
spoľahlivo overiť sklad ani cenu pri objednávke.

Riešenie:
Bol vytvorený Cart modul s repository, use-cases a API routami. Frontend teraz
číta košík cez backend a objednávka načíta ceny aj sklad z databázy v transakcii.


11. Guest a customer sessions neboli prepojené s košíkom
--------------------------------------------------------
Chyba:
Anonymný návštevník nemal bezpečnú serverovú identitu a po prihlásení sa jeho
košík automaticky nespojil so zákazníckym košíkom.

Riešenie:
Session modul používa opaque HttpOnly cookies, SHA-256 hash tokenov v databáze,
rotáciu customer session a transakčný guest-to-customer cart merge.


12. Doprava používala hardcoded nulovú cenu
-------------------------------------------
Chyba:
Vytvorenie objednávky používalo nulové hardcoded ceny namiesto údajov z tabuľky
shipping_methods.

Riešenie:
Order repository teraz načíta aktívnu dopravu z databázy, aplikuje prípadnú
bezplatnú dopravu podľa limitu a vytvorí shipping záznam s použitou cenou.
Seed dopĺňa Packeta, kuriéra a osobný odber.


Overenie aktuálneho backendu
----------------------------
- npx tsc --noEmit
- npm run build
- npm run lint (0 errors; zostávajú iba console warnings)
- npm run db:seed
- GET /api/cart -> HTTP 200 s HttpOnly guest cookie
- POST /api/cart s variantom -> položka uložená v databázovom košíku
